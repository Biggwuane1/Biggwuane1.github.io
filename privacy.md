# Postem privacy policy

Last updated: November 18, 2026

Postem is a personal automation tool used only by its owner. It runs entirely on the owner's own Mac. It has no other users.

## What Postem accesses

With the owner's permission, Postem uses the YouTube Data API and the YouTube Analytics API to upload the owner's own videos to the owner's own YouTube channel, and to read view, like, comment and watch-time numbers for those videos. It uses the official APIs of Instagram, Facebook, TikTok and X in the same way, for the owner's own accounts only.

## Where data is stored

Sign-in tokens are kept only in the macOS Keychain on the owner's computer. Post status and analytics numbers are kept in a local database on that computer. Videos and captions are sent only to the platforms the owner posts to, and for TikTok to Upload-Post, the posting service that forwards them to TikTok. Postem does not sell, share or transfer data to anyone else.

## Use of Google data

Postem's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The owner can remove Postem's access to YouTube at any time at [Google Account permissions](https://myaccount.google.com/permissions), and to other platforms in each platform's settings.
